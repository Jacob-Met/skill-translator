    Each listed optimal edge occurs in at least one complete minimum-change assignment. Combining those choices independently may introduce extra changes: the displayed witness is one coherent complete assignment.

    Counts treat each physical edge assignment as distinct. A change is one switch between adjacent marks; initial setup has no charge. This model reuses nominal tool depth and supported-width checks. It does not model clamps, collisions, travel, force, reach, duration, safe execution or physical effort.

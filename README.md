# SKILL TRANSLATOR

Make the reasoning inside skilled physical action learnable, adaptable, and transferable—without requiring everyone to move like the expert.

An expert's demonstration contains more than a sequence of poses. It contains a purpose, relationships between objects, decisions about contact and material behavior, signs that something is going wrong, and ways to recover. SKILL TRANSLATOR aims to make that knowledge available to another person using different tools, materials, or movements—and potentially to a different kind of machine.

Imagine a learner exploring a bookbinder's technique. They can inspect what an action accomplishes, ask which details matter, try an adaptation, and compare the result. The system helps them become capable, not permanently dependent on step-by-step instructions. Experts gain tools to communicate the knowledge that is difficult to put into words.

# Carry pixel-assisted learner questions into author review

The source-edge question review receives a complete saved edge exercise, with
its original PNGs, independent reports, observer dispositions, first response,
reconsideration and disclosure/candidate-inspection journal. It reuses maintained
`decision-clarification.mjs` for question admission, field eligibility, confirmed
amendment and separate retry. It does not flatten away pixel assistance.

## Original questions retain their meaning

The existing exercise consumer now offers the four already-supported authored
account references alongside before/after frame references, only after the
maintained reveal. These are choices for a future reconsideration. An existing
frame-only question is not rewritten to reference an authored field.

The reviewer can inspect a frame-only question and its original pixel evidence,
but cannot amend an account field from it. The maintained refusal remains.
For an explicitly referenced account field, the reviewer must supply a distinct
clarification, declared author/source and basis, and explicitly confirm adoption.
No explanation is generated automatically. Author identity is not authenticated.

## Preserve original assistance and source

An edge exercise remains the complete practice object in the amendment. A
transient projection into the ordinary decision reducer is used only to verify
the entire original sequence against the separately received original source.
That projection is never exported as a replacement for the original exercise.
Questions expose the first response, uncertainty, declared familiarity, full
reveal timing, report requests and exact candidate inspections with replayed
pre-answer timing. Saved derived flags are not trusted.

The source-edge reviewer shares the existing original-image/support renderer
with the exercise consumer. Candidate browsing here is explicitly a reviewer
inspection and does not change the learner's history. Missing, rejected and
unreviewed reports remain distinct. Crossings, supporting pixels and sufficient
gap certificates retain their original observational limits.

The ordinary clarification page refuses raw edge metadata that would omit its
pixel assistance, directing it to the complete source-edge review. Existing
ordinary and selective-cue clarification paths retain their existing behavior.

## Separate amendment and familiar retry

Saving a clarification retains the whole original exercise and original PNGs.
Its amended account is derived again on receiving. The original exercise,
first response, account and reports remain unchanged. A separately exported
retry uses only the explicitly changed account field, original PNGs and reports,
and a new empty exercise declaring `seen-before`. This is not an independent
unseen test or evidence of improvement. The original question and amendment
remain available as the separate saved clarification.

Import adopts only after complete source and practice validation. Invalid or
stale input preserves accepted work. New author edits retire pending exports;
a draft must be explicitly retained before saving. Complete source files are
bounded at60MiB and maintain original source images once. Page exit releases
assets; the page does not upload or invoke an external model/provider.

exercise: the former reviewer rejected its wrapper, while flattening would drop
two report disclosures, one explicit candidate inspection and five original
reports. Its actual retained question referenced only frames, correctly leaving
no authored field eligible for amendment.

Five new native groups cover complete question/assistance receiving, frame-only
refusal, confirmed eligible amendments and separate retries, source mismatch,
undeclared/unchanged answers and forged derived flags. Six existing clarification
groups preserve ordinary and selective-cue behavior. The exact maintained
fixture was received by Git blob274e97923c024a506ea480db369fcd07c224a2af.

The browser course uses actual original source media with explicitly authored
learner/author action controls. It is not an observed learner trial or an
actual expert response. Original media remain private to the permitted
experiment and are not included in the publication. Qualification receipts
separately record successful controls and environmental failures.

# Compare two pair interpretations on actual practice

Open **Task relationships → Compare pair interpretations**. Supply the original source annotation and its retained Practice session. Select two marks, a tolerance in millimetres and a basis for contrasting the criteria. If the source retains an image identity, attach the matching original PNG/JPEG before comparison; otherwise the display explicitly identifies itself as an annotation diagram.

The receiver compares the same actual pair against its fixed nominal source separation and the separation implied by the existing per-mark adapted targets. It leaves every original point rule, tolerance, placement and point assessment intact. The original image, source pair and actual sheet are separate displays: a fixed distance does not specify a corrected location. Historical and current rounds remain distinct, missing endpoints stay incomplete, and admitted photo annotations and manual detachment remain in the raw record.

This distinction can matter: a 32 mm source pair under fractional rules has a 64 mm adapted separation on a double-width sheet. Preserving 32 mm and adapting to 64 mm produce opposing conditional assessments. Opposite-edge clearances instead yield 60 → 160 mm when the width changes 100 → 200 mm; the second criterion is not assumed to be uniform scaling. At equal dimensions the expectations can coincide and provide no distinction. Different expectations can also give the same assessment for a particular attempt.

These are conditional criteria, not a preferred teaching rule. The basis can be entered after viewing results; its timing is not authenticated. Distances are nominal calibrated values with no propagated uncertainty. The maintained relationship evaluator's 1e-9 mm numerical comparison allowance is preserved and is not an uncertainty bound. No physical necessity, correction, intent, skill or learning improvement is inferred.

Download stores only admitted raw source/session and the declared pair/basis. Reopening revalidates custody and recomputes all assessments; saved derived answers are ignored. The original source image is reattached by identity after reopening. Changing source files or criteria invalidates prior visible findings.

# Frozen controls for joint workpiece continuation

Frozen before production implementation, 2026-10-28. These authored controls establish software behavior; they do not authenticate measured acquisition, expert intent, physical safety or learner benefit.

1. Original two-mark source at 100 × 80 mm starts with 25 finite combinations. Qualified first-workpiece outcomes at 200 × 160 retain left clearance for both marks. A 300 × 240 continuation must freeze guide (20, 90), index (60, 150), with one shared combination. A matching next course retains one; an incompatible next outcome yields zero.
2. Earlier round predictions and prior source records remain byte-equivalent after a later outcome. Starting a fresh training-only v1 plan still returns 25, making the continuation's explicit conditioning distinguishable.
3. Retain one original source reading for all marks and one fixed rule per mark for all workpieces; authored source-switching and rule-switching courses cannot receive a fabricated shared explanation. Empty families refuse another round.
4. Prefixes contain the complete normalized initial course and every preceding source round, without recursive derived caches. Property order is irrelevant; changing an earlier outcome, source reading, plan precision, trial identity or prospective declaration without the exact prior prefix refuses.
5. Explicitly seal the current prior evidence when freezing another round. Missing slots and above-plan radii remain visible, nonconstraining and immutable once sealed. They are not imputed or reclassified as training.
6. New outcome admission binds the entire active request/prefix, original mark anchor, dimensions, original evidence class and reported-after-plan declaration. A delayed old request cannot target a new round. Invalid replacement preserves the input account and last accepted result.
7. Global six-workpiece and 72-outcome limits include the immutable initial course. IDs and workpiece dimensions remain globally distinct and absent from training. Every original training-supported prediction must fit the proposed sheet. Unsupported seventh workpiece, malformed IDs, invalid anchors and nonfinite or out-of-range values refuse.
8. Source-only export strips derived predictions/counts and reopens deterministically. Supplied derived caches never determine results. Complete UTF-8 input and canonical output, including its final newline, stay within 4,000,000 bytes; raw exact-limit input is admitted only when its normalized sources are valid, one byte over refuses.
9. The original study, source observations and caller objects remain unchanged. The latest round can replace its own outcome slot before it is sealed; earlier sealed rounds cannot be changed through current intake.
10. Strict browser: import actual initial challenge, start continuation, freeze next workpiece with both declarations, record both outcomes, inspect retained predictions/counts/roles, export actual download and reopen on a fresh page. Reopen recomputes from sources and retains every earlier outcome.
11. Strict browser: invalid prefix, old acquisition and invalid replacement preserve the accepted sequence; late file reads lose to newer drafts. Parent activity cancels pending child imports, child activity cancels pending parent imports, and completed parent replacements visibly mark retained sequence context without overwriting it.
12. Actual 1440, 390 and 320 px layouts have no horizontal overflow, preserve readable controls and full evidence access, and support trusted keyboard submission/focus. Inspect actual desktop and narrow screenshots. Existing joint challenge and conflict groups remain live in the same composed page.

Qualification includes meaningful native assertions, the maintained surrounding native course, exact served resource/CSP checks, strict sandboxed Chrome, independent review, current-main tree/source proof, and actual merged-source verification. Broaden checks only for a concrete changed dependency or discovered risk.

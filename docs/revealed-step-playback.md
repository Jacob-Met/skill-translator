# Original context after a practice reveal

Single-sequence cue practice can optionally play the original demonstrated interval after the learner explicitly reveals the current step. The learner can compare the retained first prediction with moving and audible source context instead of relying only on the two retained stills and supplied text.

Open the original demonstration in Cue request practice. Make a prediction or explicitly reveal first using the existing control. Only after full reveal does the original-media panel appear. Pair the exact original MP4/WebM, optionally enable original audio and play the revealed step. The original file stays external to the saved practice.

The request begins at the retained before frame's actual presentation time and ends at the after frame's actual presentation time. Requested capture times are not substituted. Whole intervals must lie inside the original clip. Playback reports actual video presentation observations, not sample-exact audio boundaries.

The player admits and seeks the original while detached, then shows it at the revealed interval. Audio starts muted. Native timeline and context-menu controls are unavailable in this panel so ordinary interface use does not expose a later step through arbitrary seeking. The user still owns the original file; this is not an authenticated secrecy or familiarity guarantee.

The existing reveal chronology is unchanged. If a learner reveals before answering, playback is available and that early reveal remains recorded as assistance. If they answer first, viewing cannot rewrite that first response. Selective cue requests, missing supplied cues, reflection and self-comparison keep their existing meanings. No new event or session format is introduced, and merely playing the source leaves saved practice bytes unchanged.

Advancing to an unrevealed step or restarting retires playback and releases the clip. Source/session operations retire active work, and delayed media cannot attach across a changed practice context. Invalid replacements preserve accepted work. Reopening a practice replays its original actions and requires the external original clip to be paired again in the fresh page.

Receiving uses previously retained original voiced and silent controls and their actual PNG bundles. It covers pre-reveal lockout, initial seek before display, default muting, disabled native controls, original interval playback, byte-identical history, early-reveal drafts, restart/advance/session races and narrow keyboard reopening. These are source and interface observations, not evidence of human audibility, physical skill improvement or learning efficacy.

Cross-example transfer, original-frame assistance, author questions, amendments and familiar retries remain separate maintained consumers. Their reducers and formats are unchanged.

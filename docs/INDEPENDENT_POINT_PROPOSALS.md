# Follow a selected point relative to the other original marks

The default sampled-path proposal constrains every pair in the annotated
constellation. That can fail when a tool or task point moves relative to the
other marked points. The separate **Test the selected point independently**
action tests a conditional alternative; it does not replace the strict model.

## Model and source requirements

Select an original anchor point and included moments in `/sampled-path`. Each
comparison needs equal original sets of 4–7 calibrated points. The selected
reference point is exempt from every pair-distance constraint. All remaining
points must admit a complete bijection under the existing pair-distance bound.
Every possible observed selected point is considered. The unchanged maintained
matcher performs each auxiliary comparison, including its numerical slack.

Complete original annotations are admitted before any internal point omission,
so invalid selected points or unsupported counts cannot evade source checks.
The search-state budget is shared across all candidate omissions for one frame,
not multiplied by their number. An exhausted search cannot produce a forced
identity even when it has already found a plausible assignment. Missing or extra
original points belong to a different model and remain unavailable here.

If all complete conditional assignments share one selected pair, the interface
shows it over both original PNGs. Orange identifies the selected pair; teal marks
show the other original points. Auxiliary identities can remain ambiguous: six
ways of matching a symmetric auxiliary triangle still support just one selected
pair in the authored control. Several possible selected IDs produce no choice.
No conventional complete rigid mapping is created by this model.

## Review, adopt and reopen

Explicitly review the selected-point exemption, the auxiliary pair-distance
assumption and whether the selected pair denotes the same task point. One
combined confirmation covers those premises. **Use reviewed conditional point
choice** creates an ordinary editable point choice and basis in the existing
sample form. The independent common-plane/corner declaration and final sample
inspection remain required.

Changing source/query inputs or withdrawing a pending review retires its
unchanged generated basis. Manually corrected bases are preserved. Choosing the
conditional model retires incompatible pending rigid-review records; it cannot
feed the complete or retained rigid-subset reuse consumers. Failed source
imports preserve accepted evidence.

Save the ordinary sampled-path bundle with all original frames and authored
choices. Reopening restores that ordinary evidence, not an authenticated model
certificate or automatic semantic review. Re-run the conditional proposal against
the originals when its geometric premise needs to be inspected again. No video
or image is uploaded, no image point is drawn automatically, and original pixels,
annotations and coordinates are unchanged.

## Executed controls and limits

The authored source has selected point (40,40) and auxiliary points (10,10),
(80,10), (10,70). Moving the selected point while shuffling local IDs defeats the
strict all-point matcher. The new conditional comparison identifies its local
ID without re-entering it. A four-frame course at (40+5i,40−3i) yields an ordinary
sampled chord sum of approximately 17.493 mm. A changed course at (40+9i,40+2i)
yields approximately 27.659 mm. These are authored geometry controls, not
physical skill observations.

`node test/independent-point-correspondence.test.mjs` checks the shared budget,
complete original admission, auxiliary ambiguity, multiple possible selected
points, changed auxiliary geometry, source ordering and an independent full-
permutation oracle over 30 unfamiliar courses. The sequence adapter test checks
ordinary-path integration, selected subsets, missing/extra refusal, independent
reference declarations and source-only replay. The browser harness
`tools/browser-sequence-independent-point-proposals.mjs` exercises original PNGs,
review/retirement, strict-baseline comparison, changed original input, ordinary
save/reopen and narrow display.

The selected point, original marks/calibrations, discrepancy bound, model review
and semantic identity are still supplied. The model does not discover which real
point is independently movable, a physical joint, contact, a rigid body or task
intent. Distance compatibility can admit reflections and approximate geometry;
it is not a certified rigid transform. Even unchanged rigid data can fit this
larger family, so a compatible result does not establish physical independence.

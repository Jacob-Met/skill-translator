# Practice against demonstrated relationships

Open **Compare actual practice with supported relationships** from the raw-rule proposal page or the ordinary practice export section. Receive the complete demonstration account and an actual saved practice session. A saved comparison contains these two inputs only; reopen recomputes every relationship, target and score.

The existing five-rule raw comparison determines the surviving relationships from original per-axis bounds. The actual attempt does not eliminate a relationship or identify intent. This consumer compares each retained placement against every survivor, at the actual session dimensions, using the original authored positional tolerance. It reports agreement with all, some or none, while showing the original practice score separately. Missing placements remain missing. A supported relationship that cannot form a target at this size prevents an all/some/none assertion. Original images can be reattached using the existing hash/dimensions/type/orientation check.

The session must match the complete original practice reference, or the uniquely inferred proposal recomputed from the same raw account at those session dimensions. Foreign or stale sources are refused. A new demonstration account retires the prior comparison. All prior actual rounds remain selectable. The original session, including photo-observation metadata, remains intact; this view compares its retained point estimates and does not add a photo-uncertainty assessment.

## Demonstrated change from the baseline

On an authored width-only demonstration (100×80 point20,30 to200×80 point40,30), fraction/top/bottom remain possible. At a new273×80 workpiece they all predict54.6,30, so the actual ordinary-practice placement agrees with all three without selecting one. At273×119, the same actual54.6,30 placement agrees only with top; the original fraction score still fails. At54.6,0, it agrees with none. The earlier unique-proposal consumer cannot form one accepted proposal from this ambiguous account; this view gives a conditional comparison without manufacturing uniqueness.

This is conditional geometric evidence, not physical correctness, expert intent, demonstrated learning benefit or automated visual skill extraction. Calibration, source marks, correspondence declarations, annotation bounds and execution tolerance remain supplied. The finite five-rule model can omit the true relationship.

## Verification

`node --test --test-isolation=none test/demonstration-practice.test.mjs` checks consensus, changed dimensions, original failed score, missing and prior rounds, replay recomputation, exact original/proposal source binding, foreign sources, contradictory evidence and impossible targets.

`tools/browser-demonstration-practice.mjs` runs the maintained practice UI, enters actual placements through its form, exports sessions, and imports them into this consumer. It includes changed-input and wrong-placement controls, original PNG attachment, input-only fresh390px reopen, source replacement and prior-round selection. It uses explicit Chromium sandboxing as an unprivileged user. The small image is generated by the test; no external media is distributed.

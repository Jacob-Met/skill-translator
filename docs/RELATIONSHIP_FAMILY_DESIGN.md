# Choosing a more informative demonstration size

The maintained family comparison can now suggest workpiece sizes when more than one fixed/proportional relationship survives the original demonstrations. It enumerates combinations of 0.5, 1, 1.5 and 2 times the original width and height, excluding the unchanged reference and dimensions outside the native 1–10000 mm domain. The user no longer needs to enumerate candidate sizes or manually compare four predicted readings. This is a finite catalogue, not a search of all possible sizes.

For each surviving family, the mechanism uses the existing reference-equivalent minimum `m`, maximum `M` and exploratory range threshold `t`. A future reference-equivalent reading `z` preserves that family's full observed range exactly when `M − t <= z <= m + t`. The implementation includes the existing inference's 1e−9 mm numerical slack, scales the interval into the proposed workpiece, and intersects it with the nominal signed axis extent or nonnegative diagonal extent. It uses the unchanged maintained prediction API to obtain each scale. It does not fit a new model or introduce a measurement/execution tolerance.

Two nonoverlapping future-reading intervals mean that one exact supplied reading cannot retain both families. The catalogue is ordered by separated family-pair count, then its smallest interval gap, then area and width for deterministic ties. A suggestion must leave every surviving family nominally possible and separate at least one pair. Its display reports partial versus complete separation. Interval endpoints and gaps use round-trip-readable numeric text so tiny separations cannot collapse under three-decimal display rounding. An investigation already holding the native maximum 12 demonstrations offers no next-demonstration recommendation and preserves every source; catalogue comparisons remain hypothetical. Zero reference relationships, broad exploratory thresholds, missing evidence, contradictions and an already unique survivor do not masquerade as a successful recommendation. Nominal extent feasibility is only a necessary geometric condition; complete layout feasibility, obtainable material sizes, observation precision and acquisition cost are not established.

## Maintained consumer

Open a discovery investigation or the original discovery handoff in `/relationship-families`. The selected pair now shows automatic suggestions. Previewing the leading size updates only the hypothetical target and uses the existing source-conditioned predictions. An attached native practice session fixes dimensions and disables this preview. Starting a fresh empty comparison permits exploration without altering saved actual sessions. Existing raw review exports contain the unchanged original study and native session; suggestions are recomputed on reopen, with no cached derived ranking accepted as evidence.

Acquire and annotate a genuinely new demonstration through the existing intake to test a suggestion. A recommendation alone supplies no observation and removes no hypothesis. New outcomes can contradict every family. A future reading's exact compatibility in this software is distinct from physical measurement accuracy or demonstrated learning benefit.

## Verification

Eight native groups include 300 interval-membership probes through the unchanged inference, four independently supplied future readings at the automatically selected unfamiliar size (each retains its generating family alone), missing/contradictory/zero/broad-threshold negative controls and native dimension boundaries. Existing family and actual-practice review tests remain affected checks. The browser course `tools/browser-relationship-family-design.mjs` exercises original account intake, hypothetical preview, a new source at the suggested dimensions, actual-session preservation, raw export/fresh narrow reopen and zero-response refusal. Run results are recorded separately; a script's presence is not a passing browser claim.

Source calibration, mark placement and correspondence confirmation remain supplied. This increment reduces prospective size enumeration and family-comparison labor; it does not infer those observations, make a physical demonstration, choose a causal task requirement or establish teaching effectiveness. Existing continuous affine candidate/set investigations are separate mechanisms with their own ownership and semantics.

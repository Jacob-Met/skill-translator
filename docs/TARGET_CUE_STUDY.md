# Inspect categorical questions against separate demonstration evidence

From the cue study, open **Inspect a separate demonstrated situation**. Choose a
saved complete reference cue study and a separate saved demonstration sequence,
select its target step, and check the original sources. The maintained readers
verify the original PNG bytes and source identities. The reference examples,
categories and decisions remain unchanged.

Inspect the target's original before and after frames and supplied account. For
each category reading, explicitly select a reference cue, choose the supporting
target moment, supply a category, and attribute it as your visual interpretation
or a supplied account. A category is not inferred from the pixels or validated
by the reference table. Revising a reading replaces that exploratory draft entry;
this is not an authenticated chronological learning record.

**Compare reference questions** reuses the unchanged adaptive categorical
planner. Compatible example numbers and question branches concern the reference
records only. They do not identify the correct action in the target situation.
An unfamiliar category may leave no retained support, and unknown reference
categories remain compatible as defined by the original planner. The target is
never added to the reference table or used to refit its labels.

Save the complete investigation to retain both sets of original source pixels,
the selected target step and attributed readings. Reopen it and request findings
again; saved conclusions are not authoritative. Wrong-source or malformed files
preserve the accepted investigation. Reading edits cancel older asynchronous
source reads. Pending reading drafts disable inspection/export until retained or
discarded. The complete JSON limit is48MiB, and reference plus target share32MiB
of frame bytes and32million pixels. These are total limits, not per-side limits.

The target must have separate original clip/frame/time evidence. Renaming an
existing reference step does not turn its same before/after evidence into a new
situation. Clip provenance remains a supplied account, not authenticated proof.
No physical execution, expert correctness, teaching efficacy, independence or
skill-transfer guarantee is established by this software workflow.

Native controls: `node test/target-cue-study.test.mjs`. Actual original-PNG
consumer receiving: `tools/browser-target-cue.mjs` with the existing browser
environment. The browser course covers source pairing, attribution, full raw
download and fresh narrow reopening, wrong-source refusal and delayed-read
cancellation. Actual execution evidence must accompany normal integration.

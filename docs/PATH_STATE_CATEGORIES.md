# Timing proposals from retained authored state categories

The timing consumer can optionally use the `visibleState` descriptions already retained in two original demonstration paths. This is an additional declared constraint on geometric pairing, not semantic recognition.

Open both complete sampled-path bundles, confirm the existing point and coordinate correspondence, and choose a geometric discrepancy bound. The default remains geometry only. Enable **Also treat retained visible-state descriptions as shared literal categories** only when the originals use a consistent category convention: equal nonempty text denotes the same category and different nonempty text denotes different categories. The existing sequence admission trims outer whitespace; case, punctuation, internal whitespace and wording are otherwise significant.

Blank descriptions remain unknown and impose no category constraint. A word such as “unknown” is still literal nonempty text; the system does not interpret its meaning. Generic repeated descriptions remain uninformative. Different wording for the same real state can refuse an alignment under this convention, so a refusal does not establish physical disagreement.

Every admitted pair must still satisfy the original geometric bound. The maintained bounded monotone-coupling counter finds pairs shared by every admissible alignment. Timestamps do not select the pairing. On an authored four-stage course with repeated coordinates, four distinct existing category descriptions reduce 63 geometric alternatives to one. Empty or generic descriptions retain the ambiguity; contradictory category order and wrong geometry remain non-wins. These are conditional software-course results, not learned or observed physical skill.

Select a proposal to inspect its original PNG endpoints, annotations, timestamps and authored descriptions. Naming and adding the interval remains explicit. Changing either premise or an endpoint retires an unchanged generated basis; manually edited bases remain authored text. Successful source replacement also resets the category declaration.

Saving uses the existing complete timing bundle. It retains original paths and descriptions and the accepted interval basis, without saving inferred findings as authority. Reopening recomputes the ordinary timing report; category matching must be declared again for a new proposal inquiry. No original annotation or description is rewritten.

The source API is `proposePathCorrespondences(left, right, {sameCoordinateFrame: true, maxDistanceMm, sharedVisibleStateCategories: true})`. Omitting the last option preserves geometry-only behavior. The optional report's `stateConstraint` retains selected source descriptions, unknown sample identities and the number of otherwise geometric pairs excluded by different nonempty categories. Missing geometric observations remain unavailable.

# Audit predictions while retaining original demonstrations

Open the existing **Inspect calibrated demonstrations** workbench. Load a saved
raw demonstration account, or admit additional annotated sources with explicit
mark correspondence and coordinate bounds. Choose **Audit retained demonstrations**.
The original reference and coefficient domain remain fixed while each additional
numeric observation is omitted in turn. The complete remaining affine family
predicts that omitted workpiece through the maintained omission analyzer.

Select an omitted observation and choose **Inspect this source above**. For an
annotation-derived observation, the existing inspector selects its original
annotation and corresponding mark. Use its existing image pairing control to
reattach the original file. The maintained digest, dimensions, image type and
orientation checks still apply. Original pixels are never inferred from the
numeric coordinate. A preexisting numeric observation explicitly has no additional
annotation; inspection shows only the fixed reference.

Save with the existing demonstration-account download. The file retains the
original annotations, explicit correspondences, bounds and reference; it contains
no trusted audit findings or image bytes. Reopen and rerun to derive coordinates
and all omission classifications again. Original images must be paired separately.
Replacing an accepted account retires the old audit and its calculation. Failed
admission preserves the original account. A newer source generation cannot receive
an older worker result.

Contained, overlapping and excluded predictions retain the maintained mathematical
meaning. An incompatible remainder supplies no prediction. This is retrospective
conditional model sensitivity, not prospective validation, authenticated expert
knowledge, a faulty-observation diagnosis or measured learning. The source point,
calibration, model choice and coefficient domain are not held out.

Native source-custody controls: `node test/demonstration-holdout.test.mjs`.

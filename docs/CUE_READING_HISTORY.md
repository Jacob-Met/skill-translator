# Explain changes across the retained reading history

The withdrawal inquiry now includes **How the retained possibilities changed**. Each original record, transcript correction and withdrawal is replayed in order using the same currently declared total mismatch bound. The account lists newly possible examples, examples no longer within the bound, every retained alternative, active-reading counts and explicit correction/withdrawal reasons. Represented decision labels come from the original study; unknown labels stay unknown.

This is retrospective recomputation, not a record of past beliefs. Changing the current bound recomputes every prefix under that bound; the software does not invent historical settings. A correction replaces a transcript rather than adding an inspection. A withdrawal can reopen alternatives because it removes an active constraint, not because the excluded alternative has been verified. The complete original events remain retained and only original inputs are exported.

The whole event history is admitted before any explanation returns. Existing limits remain: 90 events, 30 introduced identities and the original declared categorical budget bounds. The final result is the unchanged withdrawal reducer result. Source images, source identities and inference rules are not edited by this display.

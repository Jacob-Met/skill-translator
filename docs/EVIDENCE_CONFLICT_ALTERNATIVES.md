# Inspect every equally small conflict explanation

When the task-space evidence panel finds several equally small contradictory
observation groups, use **Previous group**, **Next group**, or the group-number
field to inspect any of them. The visible list and all five rule-rejection witnesses
change together. Selecting an observation still opens its original sheet diagram.
The participation summary continues to describe the complete family, not just the
currently displayed group.

For 30 fixed-left observations and 30 fractional observations on the same enlarged
sheet, there are 900 smallest contradictory pairs. Group 900 remains directly
accessible; the application does not truncate the family to the first few examples.
Groups are ordered by stable observation IDs. Reordering the input file leaves a
given group number attached to the same original records.

An invalid group number preserves the accepted displayed explanation. Keyboard
navigation retains focus, and the expanded residual details remain open while
changing groups. Any ordinary source or evidence edit recomputes the family and
returns to its first group. Existing exports retain original source-bound evidence
only; the group number is a view choice, not new evidence or a saved judgment.
Reopening recomputes the complete family and begins at group 1.

## Mechanism

The existing five-rule evaluator and smallest-group report remain authoritative.
A suffix dynamic program counts completions for each remaining record position,
number of records left, and covered-rule mask. Rank selection follows those counts
to the requested group without generating earlier groups. The complete count is
cross-checked against the maintained smallest-group result. Counts and rank
arithmetic use integers; no probability or random sampling is involved.

The same limitations apply: this view concerns minimum-cardinality groups inside
five declared geometric interpretations and their supplied uncertainty checks.
Larger inclusion-minimal groups are different. Viewing an alternative does not
make its records faulty, recommend removing them, prove physical necessity, or
exclude a relationship outside the family.

## Verification

The focused native course checks every rank against independent exhaustive
geometric-subset enumeration, original rejection witnesses, input order/custody,
malformed indices, and the last of 900 groups on the full 60-record contract.
The browser course adds actual keyboard next selection, direct jump, invalid-index
preservation, and original-record inspection to the existing source/import/export
receiving path. Browser execution and maintained-source integration remain separate
gates; the test script is not a receipt by itself.

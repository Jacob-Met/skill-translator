# Declared comparable-context consistency

The evidence panel opens `/context-consistency` with the original source and every observation. No record is selected automatically. The user selects 2–60 original observations of one landmark on exactly equal sheet dimensions, supplies a context label and basis, and explicitly declares comparability. Equal dimensions alone never establish physical comparability.

The worker asks whether all selected closed uncertainty disks admit one common position. It reuses the unmodified CHRONOS `minimumConvexQuadratic` kernel pinned in `vendor/chronos/exact-circle-source-lock.json`; its existing arithmetic dependency is byte-identical. For each three-record support, it minimizes the negative weighted squared-residual dual over the complete nonnegative weight simplex. An independently reconstructed positive lower bound certifies incompatibility. A candidate common point is checked against every selected disk. Two-record and degenerate supports are retained. The certificate need not be minimal and does not identify a bad record or physical cause.

The shared 100,000-unit work bound counts input conversion, supports, kernel operations, weighted verification and full-point checks. Exhaustion returns unresolved with no partial point or certificate. Arithmetic uses exact rationals for supplied binary64 values. Existing five-rule scoring retains its separate 1e-9 mm guard and is displayed separately without changing evidence.

Saving retains only normalized source, all observations and the explicit declaration. Reopening validates source references and recomputes. Optional original PNG/JPEG reattachment verifies existing byte identity; it does not verify additional observation coordinates. Image attachment status is never persisted as a verification claim.

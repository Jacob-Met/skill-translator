# Three-frame finite appearance composition

The existing retained-frame appearance page offers a three-frame question. Choose three chronological original frames A, B and C and one common sample width and search radius. The maintained PNG reader validates their original clip, time, hash and full-resolution bytes. Each original is sampled once using the existing whole-frame Canvas convention. The maintained finite appearance kernel compares A→B, B→C and A→C independently, with the same raster, interior support, search radius and brightness convention.

The additional computation asks whether minimizing integer shifts satisfy `shift(A,C) = shift(A,B) + shift(B,C)`. It retains all three complete pair comparisons, including residuals, brightness offsets, ties and search-boundary findings. It does not add brightness offsets or residuals. At most 1,185,921 adjacent-minimum combinations are checked; pages contain at most 100 compatible index triples. The complete count, participating alternative indexes and an explicit witness for each participating alternative are retained. Every compatible triple remains accessible by page.

An empty join excludes only simultaneous choices among these finite pairwise minima. Finite support/search and changing appearance may cause this result. It does not rule out a coherent higher-residual image fit or physical motion. A nonempty join establishes no object identity, physical correspondence, action or contact. Pure shift-set reversal identities are algebraic controls only: fixed support/cropping and brightness treatment can make recomputed directed image losses asymmetric.

The v1 triplet request retains three original frame identities and the existing pair settings. Its complete original sequence and original PNGs are saved, without derived findings. Reopening validates the source and recomputes all three comparisons and the join. A pair/v1 question remains a pair; the direct Source Studio handoff still accepts original sequences without requiring an authored step. Changed frames/settings, incoming source and cancellation retire the worker and its cached pagination context.

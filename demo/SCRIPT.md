# Demo script draft: Skill Translator

Draft only. Not rendered. Dry-run checked headlessly; step screenshots in demo/steps/.

Approx. length: 236 words, about 94 seconds at 150 words per minute.

| Step | Narration | What is on screen |
|---|---|---|
| 1 | Skill Translator helps a bookbinding teacher move a marked position from one drawing to a sheet of a different size. It tells you how far off your placement is, in millimetres. | Opening view. Source drawing on the left, empty target sheet on the right, Workbenches menu top right. |
| 2 | On the left is the source drawing. It has three marks. Each mark follows a rule about where it sits. | Second mark chosen in the mark list (Center registration); the rule line updates to proportional position. |
| 3 | On the right is the target sheet, three hundred and twenty by one hundred and ninety millimetres. The red dot is where the mark should go. | Target sheet shows its 320 by 190 mm size and a red dot at the target position for the chosen mark. |
| 4 | Now place your own mark. Select the target sheet, then nudge the ring with the arrow keys. Each press moves it one millimetre. | Target sheet focused (blue outline); the ring is nudged left and up by keyboard. |
| 5 | Press Evaluate placement. The app checks your ring against the tolerance for this mark. | Evaluate placement button pressed; result line turns to a red NEEDS ADJUSTMENT message with the error in mm. |
| 6 | The result line says whether you are within tolerance, and it gives the distance in millimetres. | Result line shows error 18.4 mm against 5.0 mm allowed, with the across and down displacement. |
| 7 | Next, look at the question behind the mark. What if the mark meant a different rule? Scroll down to find out. | Page scrolled to the 'Same source, different rule' section with the rule selector visible. |
| 8 | Choose another rule to compare. Here it is a fixed distance from the top edge. The app predicts where that rule would put the mark. | Comparison rule set to fixed distance from the top edge; the outcome text shows the new alternative position. |
| 9 | Add a measurement from a second sheet size. Give the sheet size, where the mark sits, and how sure you are. | Observation form filled: label, 408 by 272 mm sheet, mark at 208 by 134 mm, 2 mm uncertainty. |
| 10 | Press Test against all five rules. Only the proportional rule still fits. The other cards show which rules this measurement rules out. | Test pressed; candidate cards show proportional position as COMPATIBLE and the other four as CONTRADICTED. |
| 11 | That is Skill Translator. Place a mark, check it, then test the rule with a new measurement. | Closing view with the observation table and the candidate cards. |
